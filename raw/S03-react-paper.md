# S03｜ReAct: Synergizing Reasoning and Acting in Language Models

- 作者：Shunyu Yao 等
- 類型：研究論文（arXiv:2210.03629；後刊於 ICLR 2023）
- URL：https://arxiv.org/abs/2210.03629
- 閱讀日期：2026-11-12

## 閱讀摘記

ReAct 研究讓語言模型交替產生推理步驟與任務行動。行動可連接知識庫或環境，取得觀察結果；觀察再協助更新後續計畫。這提供「模型提出動作—工具執行—收到結果—繼續處理」循環的研究例子。

## 支持的 Wiki 主張

- Agent loop 不只是反覆生成文字，還包括外部動作與環境回饋。
- 工具觀察可補充模型原本沒有的任務資訊。

## 限制

論文評估的是特定方法與基準任務，不能推論所有 Agent 應用都會可靠，也不應把模型內部推理展示成可直接驗證的真實理由。
