# S05｜What is the Model Context Protocol (MCP)?

- 作者／機構：Model Context Protocol 官方文件
- 類型：標準／協定介紹
- URL：https://modelcontextprotocol.io/introduction
- 閱讀日期：2026-11-12

## 閱讀摘記

MCP 是連接 AI 應用與外部系統的開放標準。官方介紹的例子包括資料來源（如本機檔案、資料庫）、工具（如搜尋、計算器）和工作流程。它提供連接方式的共同介面，讓應用可以使用外部資料或執行功能。

## 支持的 Wiki 主張

- 工具是 Agent 與外部環境互動的一種方式。
- MCP 是工具與資料整合的協定，不是 Agent 的大腦，也不保證工具結果正確。

## 限制

協定標準化連接介面，不等於授權、資料品質、模型判斷或操作安全已自動解決；實際部署仍需設定權限與檢查措施。
