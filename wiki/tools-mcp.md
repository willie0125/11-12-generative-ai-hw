# 工具、MCP 與權限

## 工具如何擴充能力

模型本身產生文字；工具提供查詢或執行外部功能的介面。典型循環是模型提出工具呼叫、系統檢查並執行、工具回傳結果，模型再使用結果繼續任務。搜尋、計算器、程式執行、資料庫查詢都是常見例子。[S03][S04]

## MCP 是什麼

Model Context Protocol（MCP）是連接 AI 應用和外部系統的開放標準。官方介紹的用途包括連接資料來源、工具與工作流程。可以把它想成「通用連接介面」：讓應用能按共同約定發現和使用外部能力；它不是模型本身，也不會自動替每個連接器判斷資料真假或授權是否適當。[S05]

## 工具權限設計

- **先讀後寫**：先以查詢或預覽為主；新增、寄送、刪除等有後果的動作要設確認點。
- **只給必要權限**：Agent 只取得完成任務需要的資料與操作能力。
- **驗證工具輸入和結果**：工具也可能失敗、回傳舊資料，或收到錯誤參數。
- **保留人工覆核與紀錄**：SDK 文件列出 guardrails、人為審核及 trace 等設計方向。[S04]
