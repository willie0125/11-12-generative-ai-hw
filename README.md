# AI Agents 入門｜LLM Wiki 與教學簡報

這份作業以 Andrej Karpathy 的 LLM Wiki 構想作為知識整理方法：保留來源紀錄，將多篇資料整理為可交叉連結的 Markdown 知識頁，再用 Wiki 回答教學問題並產生簡報。

## 成果

- [Wiki 索引](wiki/index.md)：AI Agent、工作流程、工具與限制等概念頁。
- [教學 HTML 簡報](slides/index.html)：下載後以瀏覽器開啟；方向鍵或畫面按鈕切換投影片。
- [討論紀錄與簡報大綱](docs/discussion-and-outline.md)
- [Loop / graph、查核紀錄與反思](docs/workflow-and-reflection.md)
- [Wiki 規則](AGENTS.md)

## 來源數

已 ingest 5 篇：Karpathy 的 LLM Wiki gist、Anthropic 的 agents 架構文章、ReAct 原始論文、OpenAI Agents SDK 文件、Model Context Protocol 官方介紹。每筆來源摘要在 [raw/](raw/)；整理頁保留來源標記，請由原始連結核對原文。

## 本機瀏覽

開啟 `slides/index.html` 即可，不需安裝套件或啟動伺服器。簡報自含樣式與操作程式，引用連結需要網路。
