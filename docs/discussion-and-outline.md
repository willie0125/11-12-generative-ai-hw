# 討論紀錄與教學簡報大綱

## 討論紀錄（先討論、後生成）

### 使用者先提出的選項

- 作業要求：建立至少 ingest 5 篇資料的 LLM Wiki，再以 Wiki 作為簡報知識來源。
- 對主題的初步建議：AI Agents 入門，面向初學者，介紹基本概念、運作流程、工具與限制。
- 交付偏好：本機可瀏覽 HTML；標題個人資料稍後再填。

### 使用者確認與補充

- 確認主題：AI Agents 入門。
- 指定 Wiki 方法：Karpathy 的 LLM Wiki（GitHub gist 上的構想）。
- 指定簡報：本機可瀏覽 HTML。
- 指定上傳：GitHub 帳號 `willie0125`；其後補充可建立獨立 11/12 作業 repo。

### 共同形成的內容決策

- **對象**：沒有 AI Agent 背景的初學者。
- **教學問題**：AI Agent 是什麼？它如何使用工具？Workflow 和 Agent 有什麼差異？什麼地方要加檢查？
- **範圍**：概念、簡化 loop、工具和 MCP、可靠性與適用情境。
- **來源規則**：優先用原始論文、官方文件或作者的原始說明；至少五篇；保留連結與來源編號。
- **說法規則**：Agent 定義依來源脈絡交代，不把某一種定義說成業界唯一標準；將解說用的假想例子標明為例子。
- **簡報形式**：不依賴外部套件的單檔 HTML，可用方向鍵和按鈕瀏覽。

## 簡報學習目標

看完後，學習者應能：

1. 用自己的話說明 AI Agent 和一次性聊天回答的差異。
2. 說出 Agent loop 中目標、上下文、模型、工具、觀察和停止條件的角色。
3. 分辨工具連接標準（MCP）和 Agent 本身的功能。
4. 說出至少兩個要加人工確認或權限限制的地方。

## 簡報大綱

1. 標題：AI Agent 會做什麼？
2. 從聊天到行動：一次性回答與多步驟迴圈。
3. Agent 的工作定義：有目標、用工具、讀回結果、再決定。
4. 主要組成：目標、上下文、模型、工具、循環與檢查。
5. Agent loop 圖解。
6. Workflow 和 Agent：固定路徑與動態選擇，兩者可以混用。
7. 工具與 MCP：連接能力的介面，不等於正確性保證。
8. 可靠性和安全：權限、停止條件、人工審核、trace。
9. 何時值得使用，以及重點回顧。
10. 來源。
